## Atalhos do Claude Code

- `/configurar` — instalação guiada (segue `docs/agente/configurar.md`)
- `/equipe` — liberar, listar ou remover acessos
- `/atualizar` — trazer a versão mais nova do sistema
- `/publicar` — publicar (ou republicar) na internet

Quando a pessoa precisar rodar um comando interativo (por exemplo `npx vercel login`), sugira digitar
`! <comando>` no Claude Code para rodar na própria sessão.
